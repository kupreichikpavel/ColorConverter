# Color Converter

Лабораторная работа №1 по теме **«Цветовые модели»**.

Приложение предназначено для преобразования цветов между моделями:

- RGB
- CMYK
- LAB

Вариант: **10 — CMYK ↔ LAB ↔ RGB**

Приложение написано на Java с использованием JavaFX.

---

## Возможности

Пользователь может:

- задавать цвет в модели RGB;
- задавать цвет в модели CMYK;
- задавать цвет в модели LAB;
- изменять значения с помощью ползунков;
- вводить точные значения вручную;
- выбирать цвет через Color Picker;
- видеть выбранный цвет в окне Preview;
- автоматически получать значения цвета в остальных цветовых моделях.

При изменении любой компоненты одной модели значения остальных моделей автоматически пересчитываются.

Если цвет LAB невозможно точно представить в RGB, значения RGB ограничиваются диапазоном `0–255`, а пользователю выводится предупреждение.
